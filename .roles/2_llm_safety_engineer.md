# Роль: LLM / Safety & Prompt Engineer (System 2 & PII)

## Назначение роли
Отвечает за контур глубокого семантического анализа (System 2) на базе Google Gemini API, защиту от Prompt Injection и строгое обезличивание персональных данных (PII).

## Зона ответственности (директории)
* `src/support_dispatcher/system2/` — клиент Gemini SDK, валидация ответов по схеме.
* `src/support_dispatcher/system2/prompts/` — шаблоны промптов, CoT-инструкции, изоляция пользовательского ввода.
* `src/support_dispatcher/privacy/` — детекция и маскирование персональных данных (PII).
* `tests/unit/test_system2*.py`, `tests/unit/test_privacy*.py`.

## Ключевые компетенции и задачи
1. **Интеграция с Gemini API:**
   * Использование актуального `google-genai` SDK.
   * Строгая структурированная генерация (`response_schema` через Pydantic-модели) с гарантией возврата категории только из enum таксономии.
   * Формирование Chain-of-Thought рассуждений и черновика ответа пользователю при необходимости.
2. **Безопасность и Prompt-инжиниринг:**
   * Изоляция текста тикета от системных инструкций (разделители, экранирование) для блокировки Prompt Injection.
   * Контроль отсутствия галлюцинаций в метаданных ответа.
3. **Обезличивание персональных данных (PII Masking):**
   * Предобработка текста перед отправкой в облачную LLM: маскирование ФИО, табельных номеров, телефонов, адресов электронной почты, паспортных данных, СНИЛС.
   * Обратимое или псевдонимизированное маскирование для сохранения контекста обращения.
   * Гарантия нелогирования чувствительных данных в открытом виде.

## Критерии приемки работы (по DoD)
* [ ] 100% ответов System 2 строго валидны по схеме и содержат валидную категорию из таксономии (`SED`, `DKA`, `TECHNICAL_BUG`, `FEATURE_REQUEST`, `GENERAL_INQUIRY`, `OTHER`).
* [ ] Персональные данные маскируются во всех тестовых сценариях до отправки во внешнее API.
* [ ] Устойчивость к базовым Prompt Injection атакам (инструкции из тикета не подменяют системную задачу классификации).
* [ ] Ответ System 2 формируется в пределах общего таймаута (до 3.5 с на запрос).
